# Z positions and cam-operated drawbar: planned work

สถานะ: **ข้อเสนอจากการสนทนา ยังไม่ implement** — 17 พฤศจิกายน 2026

ต้องแยกศูนย์ชิ้นงาน, จุดอ้างอิงเครื่องหลัง Homing และระดับสำหรับ ATC
ใช้ระบบพิกัดเครื่องเดียว ไม่ต้อง Homing ใหม่ทุกครั้งที่เปลี่ยนทูล
ชื่อ Z ATC Home ใน UI ควรอธิบายว่าเป็นตำแหน่งเตรียม ATC ไม่ใช่ระบบศูนย์ที่สอง

## ค่าที่เสนอ

| ค่า | หน้าที่ |
|---|---|
| `Z_NORMAL_TOP` | ขอบบนระหว่างทำงานทั่วไป |
| `Z_ATC_APPROACH` | จุดเตรียมเข้ากลไก ATC |
| `Z_TOOL_SEATED` | ระดับสวมเทเปอร์และจับทูล |
| `Z_RELEASE_START` | เริ่มสัมผัสกระเดื่อง/แคมปลดทูล |
| `Z_RELEASE_FULL` | ปลดทูลเต็มระยะ |
| `Z_CAROUSEL_CLEAR` | หัวพ้นทูลก่อนจานหมุน |

เพิ่มวิธีปลดทูลเป็น pneumatic, Z-operated cam/lever และ hybrid
กำหนดความเร็วช่วงเข้ากระเดื่อง, Timeout, Feedback และตำแหน่งก่อน/หลังรับส่งทูล
ต้องตรวจรุ่นเครื่องและกลไกจริงก่อนกำหนดลำดับ โดยไม่เหมารวม Brother ทุกรุ่น

## เกณฑ์ก่อนใช้กับเครื่องจริง

- ทุกตำแหน่งอยู่ภายในระยะเดินทางกลและขอบเขตที่อนุญาตจริง
- ป้องกัน Jog/โปรแกรมทั่วไปเข้าช่วง ATC โดยเพิ่ม MAX_LIMIT อย่างเดียวไม่เพียงพอ
- ลำดับต้องรอ actual position/velocity และ Feedback ตามที่กำหนด
- ทดสอบทั้งคืนทูลเดิม, spindle ว่าง, sensor ขัดแย้ง, Stop และ recovery
- Monitor แสดง Z เป้าหมาย/ปัจจุบัน, ช่วงกระเดื่อง และสถานะ Clamp/Unclamp

ซิมปัจจุบันใช้เพียง `z_clear` และ `vmcgui.z-clear` สำหรับภาพยกหัว
ไม่ควรตีความว่าตำแหน่งหรือ interlock ในเอกสารนี้ทำงานแล้ว
